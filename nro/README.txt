=====================================================
   BO CAI DAT SERVER NGOC RONG HASHIRAMA CHO TERMUX ANDROID
=====================================================

YEU CAU:
- Dien thoai Android cai ung dung Termux (Tai tu F-Droid).

CAC BUOC CAI DAT NHANH:
1. Mo Termux, go: termux-setup-storage (chon Cho phep).
2. Copy thu muc NRO-TERMUX vao may (vi du: /sdcard/NRO-TERMUX).
3. Trong Termux, go:
   cp -r /sdcard/NRO-TERMUX ~/
   cd ~/NRO-TERMUX
   bash install.sh

DIEU KHIEN:
- Mo menu quan ly:   bash menu.sh
- Bat server:        bash start.sh
- Tat server:        bash stop.sh
- Xem trang thai/IP: bash status.sh

CONG KET NOI:
- Game Port: 14445
- Web Admin: http://127.0.0.1:8888/admin.php (admin1 / admin123123123)

Xem chi tiet trong file: HUONG_DAN_CAI_DAT_TERMUX.md
